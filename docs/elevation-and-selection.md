## 2. 权限申请

继续以普通权限启动。只有选定操作实际需要额外能力时，提供带盾牌的授权入口，通过 `ShellExecuteExW` 的 `runas` 启动同一程序的受限 worker。GUI 和 CLI 使用相同的能力检查与 worker 协议；不靠修改整个程序为 `requireAdministrator` 解决。

| 操作 | 权限与交互 |
| --- | --- |
| 查看结果、选择、语言切换、生成选择方案 | 保持普通权限 |
| 所选 NTFS 卷快扫 | 检查卷读取能力；需要时展示“授权快速扫描 / 继续普通扫描 / 取消”，用户选择授权后才申请 UAC |
| 指定普通目录扫描 | 尝试所需的目录读取能力，不能只因未提权就拒绝 |
| 迁移、恢复、处理中断事务 | 在首次改变用户数据之前做能力预检；需要时提供授权后重新预检 |
| 外部句柄处理 | 仍须单独启用本次风险选项；UAC 同意不代表允许强关句柄，也不代表系统允许操作保护进程 |
| 已提权但仍失败 | 明确显示实际错误与覆盖范围，不反复弹 UAC、不改 ACL 或接管所有权来绕过 |
| 复制中途才发现权限问题 | 按现有事务协议安全停止并记录现场，不能提权后从头盲目重跑整批 |

MFT 回退原因、实际后端、已枚举数量、匹配阶段和覆盖不足必须即时展示。错误 5、1314 等保留数值与所选语言说明；不能把任何错误都归因为“缺少管理员权限”。不支持的文件系统、API/记录版本及其他失败分别报告。不创建 USN journal、不更改卷设置来强行开启快扫。

UAC 取消或凭据失败：当前界面、选择、目标、语言不丢失；未开始用户数据写操作，不自动转为另一种写入方式。快扫允许用户明确选择普通枚举；同一次任务不循环询问。

worker 约束：

1. 只接受受支持操作、明确源/目标和有限大小的结构化请求，不接受任意程序、命令行或可执行规则。
2. 使用本机受 ACL 约束的通信通道，绑定父子进程身份、进程创建时间与一次性会话；不能仅凭可编辑请求文件、自报 PID 或自报散列建立信任。校验双方的映像对象身份，限制报文长度、深度与次数；拒绝远程、无关进程及重放请求。
3. 提权后重新核验卷、对象、连接、选择范围、目标冲突和事务状态。散列用于绑定已经确认的计划，不能代替身份鉴别和路径安全检查。
4. 传递发起用户的明确上下文：源路径、状态目录、规则快照/版本、语言和已确认选项。通过另一管理员账号授权时，不能把管理员自己的 USERPROFILE、LOCALAPPDATA 或语言偏好当成发起用户的设置。
5. 一个 worker 只服务当前选定操作并退出；没有常驻服务、驱动或保存的管理员凭据。取消、管道断开或父进程退出均进入现有安全停止/恢复协议。
6. 保持 Win7 原生 API 与系统 DLL 边界；新增导入、体积和实际 UAC 交互需独立验收。

技术依据：[CreateFileW 的卷访问要求](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew#physical-disks-and-volumes)、[ShellExecute 的 runas / UAC](https://learn.microsoft.com/en-us/windows/win32/shell/launch#object-verbs)。提权会启动新进程，不能让运行中的普通进程原地变成管理员。

## 3. 目录根与树的定义

“智能提取根”指**规则已识别且允许整体迁移的最外层目录**，不是取所有命中的公共祖先。例如 `npm-cache` 与其中的 Claude 包合并为一个默认折叠的候选根；不能因此扩大为整个 AppData、用户主目录或磁盘。

只折叠显示，不丢弃子节点、规则命中理由、已有连接或阻塞信息。没有被允许的候选父目录时，保留较精确的子目录；不能仅凭目录名、多个相邻命中或点开头命名推导安全父根。显式添加目录仍走保护策略。

GUI 使用原生 `SysTreeView32`，展示真实路径层级、文件夹展开、checkbox 和未选/全选/半选状态。父子级联由共享核心计算，原生控件只负责显示与输入。大小、状态、目标和原因在选中节点的详情区与执行预览中展示，不为多列树引入 GUI 框架或第三方 DLL。

| 节点 | 选择含义 |
| --- | --- |
| 磁盘、Users、AppData 等导航节点 | 只组织路径；批量操作只能选择其中的合格候选，节点自身永不生成迁移任务 |
| 可整体迁移的候选目录 | 全选代表整个目录，子孙显示继承勾选；执行时只生成该根的一项事务 |
| 已有 junction / 目录 symlink | 作为边界展示 `连接路径 → 真实目标`，迁移模式不可再选；恢复模式才允许按支持条件选择 |
| 阻塞或未知节点 | 显示原因；祖先勾选不能越过阻塞把它强行纳入 |

默认所有节点不勾选。候选根默认折叠；展开时再加载普通子目录，不能把全盘几十万节点一次塞进控件。惰性加载节点继承共享选择意图，而不是只对屏幕上已加载的子节点打勾。未完成覆盖或存在不明节点时，不能声称父根已经完整安全。

恢复树使用连接所在的**逻辑路径**组织，不能把真实目标的内容嫁接到连接节点下面后继续递归。多个逻辑连接指向同一对象时仍是不同恢复项；目标引用关系单独展示，保留目标的规则不变。

## 4. 勾选与计划归并

共享选择模型位于核心，不放在 GUI 的控件事件里。模型保存节点关系、选择意图和排除子树；生成的执行计划仍是显式、扁平且互不重叠的目录项。

| 操作 | 选择结果 | 执行计划 |
| --- | --- | --- |
| 勾选目录 A | A 全选，所有子孙继承 | 只有 A；不另执行 A/B、A/B/C |
| 同时传入 A、A/B、A/B/C | 与输入顺序无关地归并 | 只有 A，预览列出被覆盖的重复项 |
| 只勾选 A/B | 祖先按范围显示半选 | 只有 A/B，不自动扩成 A |
| 全选 A 后取消 A/B | A 半选，排除整个 B 子树 | A 自身不迁移；只迁移其余完整选中的子目录 |
| 再取消 A/B/C 的排除 | 根据完整子树覆盖重新计算 | 只有明确覆盖全部内容、仍合格且选择意图允许时，才能重新成为 A 整体任务 |
| 勾选导航分组或执行全选 | 只选择合格候选根 | 不把导航分组升级为真实迁移根 |

**半选的限制必须明确告知：**现有产品只迁移目录。父节点半选时，父目录直属文件和未选内容留在原处；不能同时在父路径建立根 junction。选定子目录有直属文件时，其作为完整目录迁移会包含那些文件。预览逐项展示“完整迁移的目录”和“保留在原位置的直属文件/排除目录”，不能暗示实现了“父目录整体迁移但留下一个例外”的根连接。

惰性加载未完成时，排除操作的归并必须先解析受影响的目录分支，再生成有限且准确的任务列表。没有允许的目录任务可表达某种选择时，说明原因并阻止执行，不静默搬运未选内容。取消某分支后，不因同级全选就跨越被排除节点做父级合并。

生成计划必须满足：去重、归并幂等、输入顺序无关；每个项只执行一次；没有源-源、目标-目标、源-目标重叠；总体容量不把父子体积重复相加。逻辑路径、卷/文件身份与最终解析目标分别保存；不能只靠字符串去重，也不能因两个恢复连接具有相同真实目标就合并掉其中一个。

原生 tree-view 的 checkbox 样式只提供基础状态图像；级联、半选、继承和禁用规则由项目实现。[微软 Tree-View 样式说明](https://learn.microsoft.com/en-us/windows/win32/controls/tree-view-control-window-styles)

## 5. 已迁移子目录的处理

例如已将 `A/B` 迁移为 junction，再选择 A：

1. 列出 `A/B → 真实目录`；A 显示“含已迁移子目录，不能整体迁移”，不显示 ready。
2. 可改选 A 中其他合格、未迁移的子目录；A 保留。不能忽略 B 后仍声称整体迁移成功。
3. 若希望最终把 A 整体迁走，需要先在恢复模式把 B 恢复成真实内容，再重新扫描 A、核验、预览、确认。此版本不自动串联“恢复子项再迁父项”。
4. 扫描、计划及写入前分别检查，抵御扫描后才新增的连接；旧报告不能绕过。最终引擎的重叠检查、reparse 检查及事务保护继续保留。
5. 相对内部 symlink、模型链接、硬链接仍按各自支持策略校验；不能把所有链接当普通内容展开。未知、不支持或无法证明安全的对象阻塞整体迁移。

迁移完成后刷新受影响的祖先、子节点、连接状态与选择，不沿用执行前的 ready 和勾选快照。

## 6. CLI 等价表达（0.1.1-dev.1）

保留既有 `scan → plan → apply`，简单选择继续用 `--select id1,id2`。复杂树选择使用 `--selection selection.json`；二者互斥。GUI 保存/加载相同选择文件，并使用相同选择核心，不把树控件当唯一事实来源。

```json
{
  "version": 1,
  "include": ["C:\\Users\\Example\\AppData\\Local\\npm-cache"],
  "exclude": ["C:\\Users\\Example\\AppData\\Local\\npm-cache\\_npx"]
}
```

选择文件 version 1 使用绝对逻辑路径，不能用翻译名或行号定位。路径必须位于扫描候选根内；加载时重新检查实际目录，拒绝别名逃逸、未知字段、矛盾输入及超限。最具体的包含/排除意图生效。文件不携带可信快照身份，不能仅凭它声称对象未变化，执行前仍须重新预检。GUI 保存的 `FreePort-selection.json` 可直接交给 CLI，不含凭据、风险开关授权或可执行内容。

用法：

```powershell
fp scan --volumes C: --mode migrate --out scan.json --elevate
fp plan --scan scan.json --selection selection.json --destination D:\Dev --out plan.json
fp apply --plan plan.json --elevate
```

`--elevate` 只是显式允许必要时申请 UAC，默认关闭；已具备能力时不重复申请。它不等于 `--yes`，不启用正常退出或强关句柄。脚本默认不弹 UAC；需要额外权限时返回明确、稳定的错误和提示，由调用方选择显式授权或从已提权终端运行。无法交互、用户拒绝、已提权仍拒绝是不同结果，不无限重试。

旧扫描报告与 `--select` 保持兼容；扫描 JSON 保持原格式；选择文件独立带 version，不信任外部输入。参数、选择字段和计划字段不本地化；人类说明按现有六语翻译。

执行预览和 plan 文件必须展示实际归并后的任务、覆盖掉的重复项、排除/阻塞和保留内容。CLI 不需要模拟 GUI 点击，也不需要用不透明的 JSON 动作指令代替现有清晰命令。恢复的选择仍解析成明确连接路径，复用原恢复事务，不复用迁移的根合并规则去吞掉独立连接。

| 统计 | 根与子孙体积不重复计入计划；已有连接目标、共享内容、未完成统计均不能伪称可释放量 |
| 两端一致 | 同一扫描与选择，GUI 和 CLI 得到相同有序任务、映射、保留内容与阻塞，不只比较控件勾选 |
| 事务 | 提权前不更改用户数据；中途拒绝/取消/崩溃与批次部分完成继续遵守原日志恢复协议 |
| 平台 | Win7 SP1 x64、较新 Windows、UAC 与六语长文本、高 DPI、屏幕阅读器和内存/EXE 体积；实机结果单列 |

0.1.1-dev.1 已实现原生目录树、选择文件、共享任务规划、实时回退诊断与按次提权 worker。GUI 的规划和执行是两个独立确认步骤，未提升的会话勾选管理员选项时可能分别请求 UAC；不缓存管理员凭据。46 项单元测试中 37 项通过，原有 9 项原生夹具遇系统拒绝访问；新增 10 项核心测试通过。实际 UAC 交互/跨账户授权、Win7、断电及完整原生数据安全门槛仍待验收。本版本只作开发预览，不能标记为全部验收完成。
