## 当前验证结果

- 六语 CLI / 原生 GUI 接口测试：8/8 通过，包括偏好损坏回退、显式覆盖、只读扫描、稳定 JSON 字段、规则包升级、状态保持和六语原生确认按钮。
- 边界单元测试：共 36 项；27 项通过，9 项因系统拒绝访问失败，未跳过任何用例。内含 5,000 组路径边界和 20,000 组畸形 MFT 输入。大量断言不等于覆盖所有文件系统故障。
- 原生迁移相关 9 项测试在当前受限环境遇到系统错误 5（拒绝访问），涉及创建硬链接/junction 或写入 ACL。仍是失败，不能按通过发布。
- 新增目录固定测试曾发现只使用 `FILE_READ_ATTRIBUTES` 不能阻止改名，已改用目录读取权限；“持有时阻止改名、释放后允许改名”用例已通过。
- 专用句柄验收未通过：本机拒绝 `NtQuerySystemInformation(SystemExtendedHandleInformation)`，未执行任何实际用户应用的句柄关闭。
- PE 检查：开发构建的 CLI/GUI 均通过体积和导入检查，没有第三方运行时 DLL 导入；精确字节数见打包的构建报告。
- 尚无 Windows 7 实机、VM 断电、拔盘、完整 PID/句柄复用/映射压力和大规模 MFT 性能证据。CI 流程已编写，尚未在 GitHub 上运行。

## 规则包边界

规则为 UTF-8 JSON，只有版本、显示名称、相对目录后缀、类别和进程名等数据。`fp rules --import pack.json --state PATH` 在锁和原子替换下安装更高 revision；未知字段、路径穿越、重复 ID、超限、同版或降级均拒绝。`fp scan --state PATH` 使用该状态目录中的规则。

首版提供离线导入，不安装后台更新服务。规则只能补充候选，不能执行程序、发起迁移、绕过保护目录、默认勾选候选或开启强关。内置规则可关联六语名称；用户自建名称按原文显示。保护策略属于核心代码，不属于可更新规则包。
