## 已实现

| 范围 | 现状 |
| --- | --- |
| 扫描 | 自研 `FSCTL_ENUM_USN_DATA` 枚举与 USN_RECORD V2 解析、路径重建；权限不足或不支持时回退只读 Win32 遍历并即时显示原因。范围为用户目录及其中的 AppData，报告含 `scope_roots` |
| 候选规则 | schema v2 知识库（revision 2026102401，105 条规则），路径锚定并要求应用标志；仅有名称的 v1 规则不产生候选。见[应用存储调研](application-storage-research.md) |
| 选择 | 原生 SysTreeView32 目录树（继承、半选、按候选根归并）、共享选择核心、CLI `--selection`、列按递归逻辑大小降序，链接明细进入 CLI JSON |
| 迁移 | 系统 robocopy 暂存复制 → 逐流 SHA-256 等校验 → 切换 → `/MOVE` 收尾 → 仅移除空目录 → `mklink /J`；内部硬链接用 `mklink /H` 重建。参数见[系统命令后端](system-command-backend.md) |
| 恢复 | 从盘上实际连接（含手工创建、无历史记录）复制真实目标当前内容替换连接，真实目标保留；整卷 MFT 扫描可发现 VHD 上的手工 Junction |
| 中断恢复 | 预写日志、阶段回放、`recover`；批次台账单独记录单目录与整批结果；复制开始前被拦截（内部连接、外部硬链接、空间不足）的事务直接记为 `rolled_back`，不阻塞后续操作 |
| 提权 | 按需 UAC，一次性 worker，本地 ACL 管道与对端身份核验；不保存凭据 |
| 占用 | 只检测并展示。GUI 无强关与请求退出开关；发布版 CLI 将 `--request-app-exit`、`--force-close-handles` 作为未知参数拒绝；`handles::release` 收到任一选项即拒绝。`handles` 代码保留给下一目标 |
| 多语言 | 六语资源保留，冻结不维护 |
| 构建 | Windows 10 / 11 x64；stable 工具链、`x86_64-pc-windows-gnu`、静态 CRT，PE 导入与体积检查。不再支持 Windows 7/8 |

## 已知限制

- 收尾阶段同时持有所选项的文件/流保护句柄，资源随规模增长，有界批次未实现。
- 同卷迁移同样走复制协议，不释放本卷空间。
- 已修复：整卷 MFT 扫描因 FSCTL_ENUM_USN_DATA 不返回根目录记录 5 而解析出 0 条路径；路径解析现以记录 5 为卷根。
- 已修复：整卷恢复扫描不再列出 Windows 管理、node_modules 内和同盘目标的连接，并跳过容器层重解析目录。本机 C: 由 1282 项、约 1 分 40 秒降为 11 项、约 11 秒（调试构建）。
- 已修复：`fp handles` 在本机约 300 万句柄、OneDrive 同步服务持有阻塞句柄时，单个名称查询可阻塞 10 秒以上，整次查询超过 30 秒上限。现每个句柄限时 500 毫秒，超时取消同步 I/O 并换工作线程，同一进程两次超时后其余句柄只计数；未解析数写入提示。本机由约 27 秒或超时降为约 2 秒。检测现包含 Windows 目录下的进程（资源管理器、命令行），强关仍排除。
- MFT 大卷首屏、USN 增量刷新没有正式基准；断电、拔盘、文件映射、PID/句柄复用压力没有自动化证据。
- 大小为逻辑字节，不是 NTFS 簇占用；外部硬链接去重未实现。
- 产品尚未自动关联安装清单或解析应用自定义根与环境变量。
- 项目许可证未选择。
